# 資料庫 · Character Library

[English](README.en.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · **繁體中文** · [简体中文](README.md)

> 只在自己電腦上跑的動漫 / cosplay 素材庫。
> 圖片和影片以 **資料庫 → 條目 → 圖包 → 圖片 | 影片** 四層歸位，磁碟上的資料夾結構和畫面階層一一對應。
> 瀑布流瀏覽、標籤、漫畫閱讀器、壓縮檔自動解壓、增量磁碟同步，全部內建。
> **資料完全留在本機：不上雲、不上傳、不聯網。**

**它不是掃描器。** 素材是**複製**進資料庫的，歸你管、可分類、可編輯；來源資料夾一個位元組都不動。

> 介面與程式碼註解**只有簡體中文**（程式本身沒有做多語系）。
> 這份文件是精簡版；完整手冊（每個畫面的說明、API 一覽、調校紀錄、已知問題、版本歷史）
> 在 [README.md](README.md)（簡體中文）。

## 能做什麼

- **五種資料庫型態** — 人物（cosplayer + 帳號欄）、角色（依作品分組）、資源（每部作品一張卡）、
  表符 / 散圖（扁平）、小說（TXT 站內閱讀 + 插圖 + 漫畫袋）。另外還有一個「全部資料庫」，
  用來先收雜圖再分發。
- **四種進料方式**
  - 拖曳上傳：單次 400 個、單檔 4 GB，附進度與每個檔案的失敗原因
  - **壓縮檔直接拖**：zip / rar / 7z / tar.gz 自動解壓，只收圖片與影片。zip 由程式自己解析
    （GBK 檔名不會亂碼），**加密壓縮檔會詢問密碼並記住**
  - 從資料夾批次匯入：以 sha256 去重、依檔名日期建立圖包；`--move` 會先確認資料庫裡的副本
    完整，才刪除來源檔
  - **桌面殼拖曳**：瀏覽器只拿得到位元組，殼拿得到真實路徑 —— 所以**匯入成功後可以直接刪掉原始檔**
- **瀏覽** — 瀑布流分段繪製（上萬張也不卡）、四種排序、寬圖跨兩欄、縮圖在入庫時就產生
- **標籤** — 圖包名稱「角色-服裝」會自動拆成兩個標籤，條目名稱本身也是標籤，點標籤跳到標籤頁
- **搜尋** — 頂端搜尋框涵蓋資料庫列表、條目、資源庫、資源詳情；伺服器連標籤一起比對，
  打作品名也能找到只掛了該標籤的條目
- **漫畫閱讀器** — 連續捲動 / 單頁 / 雙頁、右到左、適高 / 適寬、全螢幕、滾輪翻頁，
  視窗變窄時側欄自動收小
- **批次與鍵盤** — Shift 連選、Ctrl 加減、`Ctrl+A` 全選、Delete、Esc，幾乎每個元素都有右鍵選單
- **磁碟同步** — 每次改名 / 移動 / 刪除，都在**與資料變更同一個交易**裡寫一筆操作紀錄；
  同步鈕只處理這些差異、不掃整個資料庫，而且**不會刪掉不是自己放進去的檔案**
- **備份** — `VACUUM INTO` + 抽樣雜湊驗證 + MANIFEST，保留最近 5 份

## 技術組成

| 部分 | |
|---|---|
| 前端 | 原生 ES Modules，**零建置**（沒有 webpack / vite / 打包步驟），CSS 變數 + 手寫元件 |
| 後端 | Node 22 · Express 5 · better-sqlite3 · sharp（libvips）· ffmpeg |
| 桌面殼 | Rust · tao + wry（WebView2），**689 KB 單一 exe**，靜態連結 CRT，不需要任何 dll |
| 儲存 | SQLite 索引 + 磁碟上的原件；路徑以資料根目錄的**相對路徑**儲存，換硬碟不必改資料 |

## 快速開始

需要 **Node.js 20 以上**（開發與測試用 22）。第一次啟動會自動建立資料庫。

```bash
cd server && npm install && cd ..
start.bat          # 啟動服務並開啟 http://127.0.0.1:7788
```

資料目錄預設是 `E:\CharacterLibrary`，要換位置用環境變數：

```bat
set CL_DATA_DIR=D:\MyLibrary
set CL_CACHE_DIR=D:\my-cache
start.bat
```

想要「雙擊一個檔案就能用」而不是開瀏覽器，再建置桌面殼
（Windows 上需要 Rust 工具鏈與 VS2022 Build Tools）：

```bash
node desktop/build.mjs      # 產出專案根目錄的 资料库.exe
```

exe 必須留在專案根目錄（它會往上找 `server/src/index.js`）；想放桌面請建立捷徑。

## 資料放哪

| 位置 | 預設路徑 | 內容 |
|---|---|---|
| 程式 | 儲存庫資料夾 | 程式碼、`web/`、`server/`、exe、`.cache`（縮圖，刪掉會自動重建） |
| 資料 | `E:\CharacterLibrary`（`CL_DATA_DIR`） | 原始媒體 + 索引 `.catalog\library.db` |
| 備份 | `E:\CharacterLibrary-Backup`（`CL_BACKUP_DIR`） | 每次執行產生一個時間戳資料夾，保留 5 份 |

建議：**資料放機械硬碟**（容量大、循序讀取），**快取放 SSD**（縮圖多為隨機讀取）。

## 已知限制

- 單檔上限 4 GB，單次最多 400 個（壓縮檔同樣適用）
- 解 rar / 7z 需要安裝 7-Zip 或 WinRAR（Windows 內建的 `tar.exe` 也可以）；zip 不需要任何工具
- `mkv` / `avi` 瀏覽器可能無法直接播放
- 在同一個條目內把素材移到別的圖包時，只改資料庫，檔案要等下次同步才搬
- 桌面殼僅支援 Windows（WebView2）；網頁版本身只要跑得動 Node 就能用
- **介面只有中文。** 沒有 i18n 層，也沒有加入的計畫。
