# 資料庫 · Character Library

[English](README.en.md) · **日本語** · [한국어](README.ko.md) · [繁體中文](README.zh-TW.md) · [Русский](README.ru.md) · [Français](README.fr.md) · [简体中文](README.md)

> 自分のマシンだけで動く、アニメ・コスプレ向けのローカル素材ライブラリ。
> 画像と動画は **ライブラリ → エントリー → パック → 画像 | 動画** の四階層で管理され、
> ディスク上のフォルダ構成は画面の階層とそのまま一致します。メイソンリー表示、タグ、
> コミックリーダー、圧縮ファイルの自動展開、差分のディスク同期まで全部入り。
> **データは一切外部に出ません。クラウドもアップロードも通信もありません。**

**これはスキャナではありません。** 素材はライブラリへ**コピー**され、自由に分類・編集できます。
元のフォルダには一切手を加えません。

> 画面とコードのコメントは**簡体字中国語のみ**です（アプリ自体の多言語対応はしていません）。
> このファイルは概要版です。全画面の説明・API 一覧・チューニング記録・既知の問題・
> バージョン履歴まで含む完全なマニュアルは [README.md](README.md)（中国語）にあります。

## スクリーンショット

**ライブラリ一覧** — カード 1 枚が 1 エントリー、右下のバッジはパック数。
上部のバーでライブラリを切り替え、検索ボックスはライブラリ全体を横断します。

![ライブラリ一覧](docs/screenshots/shelf-grid.jpg)

**エントリー詳細** — 左にカバーと件数、中央に出典・別名、その下にパック一覧。
「すべてのメディア」に切り替えるとこのエントリー下の全ファイルを表示します。

## できること

- **5 種類のライブラリ** — 人物（コスプレイヤー＋アカウント欄）、キャラクター（作品ごとに分類）、
  リソース（作品 1 件につきカード 1 枚）、絵文字／バラ画像（フラット）、小説（TXT ビューア＋挿絵＋
  コミック袋）。このほかに、配布前に雑多なファイルを溜める「全部ライブラリ」があります。
- **素材を入れる方法は 4 通り**
  - ドラッグ＆ドロップ：1 回 400 ファイル、1 ファイル 4 GB まで。進捗と失敗理由を表示
  - **圧縮ファイルを放り込む**：zip / rar / 7z / tar.gz を自動展開し、画像と動画だけを取り込みます。
    zip は自前で解析（GBK のファイル名も文字化けしない）。**暗号化 zip はパスワードを尋ね、記憶します**
  - フォルダから一括インポート：sha256 で重複排除、ファイル名の日付からパックを作成。
    `--move` はライブラリ側のコピーを検証してから元ファイルを削除します
  - **デスクトップシェルへのドラッグ**：ブラウザはバイト列しか受け取れませんが、シェルは実パスを
    取得できるため、**取り込み成功後に元ファイルを削除**できます
- **閲覧** — メイソンリーを分割描画（数万枚でも引っかからない）、4 種類の並び替え、
  横長画像は 2 列にまたがる、サムネイルは取り込み時に生成
- **タグ** — 「キャラクター-衣装」のようなパック名は自動で 2 つのタグに分割。エントリー名も自動で
  タグになり、タグをクリックするとタグページへ移動
- **検索** — 上部の検索ボックスがライブラリ一覧・エントリー・リソース一覧・リソース詳細を横断。
  サーバー側はタグも検索するので、作品名を打つとタグだけ持っているエントリーもヒットします
- **コミックリーダー** — 連続スクロール／単ページ／見開き、右から左、高さ合わせ／幅合わせ、
  全画面、ホイールでページ送り、狭いウィンドウではサイドレールを自動で縮小
- **一括操作とキーボード** — Shift で範囲選択、Ctrl で追加／解除、`Ctrl+A` で全選択、Delete、Esc。
  ほぼすべての要素に右クリックメニューがあります
- **ディスク同期** — 名前変更・移動・削除のたびに、データ変更と**同じトランザクション**で操作ログを
  記録します。同期ボタンはその差分だけを処理し、ライブラリ全体を走査しません。
  また、自分が置いていないファイルは決して削除しません
- **バックアップ** — `VACUUM INTO` ＋ サンプリングしたハッシュ検証 ＋ MANIFEST。直近 5 世代を保持

## 技術構成

| 部分 | |
|---|---|
| フロントエンド | 素の ES Modules。**ビルド工程なし**（webpack / vite / バンドラ不使用）、CSS 変数と手書きコンポーネント |
| バックエンド | Node 22 · Express 5 · better-sqlite3 · sharp（libvips）· ffmpeg |
| デスクトップシェル | Rust · tao + wry（WebView2）。**689 KB の単一 exe**、CRT 静的リンク、同梱 DLL なし |
| 保存形式 | SQLite のインデックス＋ディスク上の原本。パスはデータルートからの**相対パス**なので、ドライブを移してもデータを書き換えずに済む |

## クイックスタート

**Node.js 20 以上**が必要です（開発・検証は 22）。初回起動時にデータベースが自動で作られます。

```bash
cd server && npm install && cd ..
start.bat          # サーバーを起動し http://127.0.0.1:7788 を開く
```

データディレクトリの既定値は `E:\CharacterLibrary` です。変更する場合は環境変数で指定します。

```bat
set CL_DATA_DIR=D:\MyLibrary
set CL_CACHE_DIR=D:\my-cache
start.bat
```

ブラウザではなくウィンドウで使いたい場合は、デスクトップシェルをビルドします
（Windows 上で Rust ツールチェーンと VS2022 Build Tools が必要）。

```bash
node desktop/build.mjs      # プロジェクト直下に 资料库.exe ができる
```

exe はプロジェクト直下に置いたままにしてください（`server/src/index.js` を上方向に探します）。
デスクトップに置きたいときはショートカットを作ってください。

## データの置き場所

| 場所 | 既定パス | 中身 |
|---|---|---|
| プログラム | リポジトリのフォルダ | コード、`web/`、`server/`、exe、`.cache`（サムネイル。削除しても再生成されます） |
| データ | `E:\CharacterLibrary`（`CL_DATA_DIR`） | 原本メディア＋インデックス `.catalog\library.db` |
| バックアップ | `E:\CharacterLibrary-Backup`（`CL_BACKUP_DIR`） | 実行ごとにタイムスタンプ付きフォルダ、直近 5 世代 |

データは HDD（大容量・シーケンシャル読み込み）、キャッシュは SSD（ランダム読み込みが多い）に置くのがおすすめです。

## 既知の制限

- 1 ファイル 4 GB、1 回 400 ファイルまで（圧縮ファイルも同じ）
- rar / 7z の展開には 7-Zip または WinRAR が必要（Windows 標準の `tar.exe` でも可）。zip は追加ツール不要
- `mkv` / `avi` はブラウザで再生できない場合があります
- 同じエントリー内でパック間を移動した場合、データベースだけが更新され、ファイルは次回の同期で移動します
- デスクトップシェルは Windows 専用（WebView2）。Web アプリ自体は Node が動く環境ならどこでも動きます
- **画面は中国語のみです。** i18n の仕組みはなく、対応する予定もありません。
